# DonutSMP Hub

A community companion site for the **DonutSMP** Minecraft server.

Live site: `https://YOUR_USERNAME.github.io/donut-hub/`

---

## Features

- **Blog carousel** with expandable posts and 3D wheel navigation
- **Live player count** pulled from mcstatus.io, refreshes every 60 seconds
- **Copy-to-clipboard** server IP and port with visual feedback
- **Rules and Policies** page with searchable accordion
- **Store** page with ranks and shards
- **Leaderboards** for money, kills, deaths, playtime, shards, and more
- **Discord community widget** with live member count
- **Custom cursors** (crystal default, ender pearl on nav)
- **Minecraft-style effects** including explosion on click, teleport sound on page change, and purple particle vignette on load

---

## Stack

- HTML5
- CSS3 (vanilla, no framework)
- JavaScript (vanilla, no framework)
- Google Fonts: Press Start 2P, Montserrat, Inter

No build step. No dependencies. Just open `index.html`.

---

## Local Development

**Option 1** - double-click `index.html`, it opens in your browser.

**Option 2** - use Live Server:

1. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code
2. Right-click `index.html` and select **Open with Live Server**

Live Server gives you auto-reload on save and is required if you plan to test the leaderboard API (CORS).
