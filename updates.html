February 11, 2025 Rule

⚠️ New Rule: No External Gambling

Gambling is an action where users bet coins, items, or other value for an uncertain prize, and it's not allowed if you're betting on chances outside of the server.

Examples of what's now banned:

  • Casinos
  • Coin flip
  • Chance games
  • Lotteries
  • Raffles

You are not allowed to gamble using Discord bots or any other external tools anymore. This rule was added because people were intentionally promoting massive external gambling operations.
